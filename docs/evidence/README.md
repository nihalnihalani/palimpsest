# Evidence

This directory holds the runtime artifacts the hackathon brief asks for —
proof that the wiki actually got smarter, not theatre.

## Files

| File | What | Generated by |
|---|---|---|
| `vector_provider.json` | Resolved cognee vector backend (catches the old `.env.example` bug) | `wiki vector-smoke` |
| `eval_baseline_runs.json` | N=5 `wiki eval` runs *before* the canned contradiction items are ingested | `wiki evidence --label baseline` |
| `eval_improved_runs.json` | N=5 `wiki eval` runs *after* `wiki seed && wiki ingest` | `wiki evidence --label improved` |
| `eval_summary.json` | Median scores + missing terms per label (compact) | `wiki evidence` (auto-merged) |

## Reproducing live

The live capture is *deferred* in this branch — running it needs:

1. A Gemini API key in `.env`: `cp .env.example .env && echo "GEMINI_API_KEY=sk-..." >> .env`
2. Redis Stack running locally: `docker compose up -d` (or `brew services start redis-stack-server`, or use Redis Cloud — set `REDIS_URL` in `.env`)

Then, from the repo root:

```bash
./run.sh setup            # idempotent — confirms venv + Redis bringup
wiki vector-smoke         # rewrites vector_provider.json with current state
wiki doctor               # one-shot diagnostic; bail out if any line is red
wiki reset                # clean slate
wiki load-baseline        # hand-authored baseline concept pages
wiki evidence --label baseline   # N=5 baseline eval (no canned items yet)

wiki inject-canned contradiction_1
wiki inject-canned contradiction_2
wiki inject-canned contradiction_3
wiki ingest --once         # ×3 (or `./run.sh seed` to drain the stream)
wiki ingest --once
wiki ingest --once

wiki evidence --label improved   # N=5 improved eval

# self-improvement loop (the hackathon's required SkillRunEntry path)
wiki improve --remember                                              # ingest ./my_skills
wiki improve --run code-review --prompt "Review the latest rewrite"  # exercise a skill
wiki improve --record code-review --score 0.3 --task-text "..."      # propose
wiki improve --status                                                # show last_proposal.proposal_id
wiki improve --apply <proposal_id>                                   # commit the SKILL.md rewrite
```

The eval median should move from baseline → improved as the canned contradiction items get distilled into the graph and the relevant concept pages get rewritten with `SUPERSEDES` provenance.

## Cost note

Each `wiki evidence --label X` issues ~5 Gemini calls (one per run + one grader call). Total: ~10 Gemini calls for the full before/after capture. The skill loop adds a handful more.
